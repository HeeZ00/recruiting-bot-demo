# 피플봇 — 채용 콘텐츠 생성기 (데모)

**우리 회사 콘텐츠를 학습해 채용 콘텐츠를 만드는** 로컬 데모입니다.
어떤 회사/조직의 기존 JD·회사 소개·브랜드 보이스를 **참고 콘텐츠**로 넣으면,
봇이 그 미션·말투·구조를 학습해 같은 톤으로 결과물을 생성합니다.

웹 화면에서 바로 생성하고 확인할 수 있어요. 현재 탭(기능):

- **JD 작성** — 채용 요청서 + 참고 콘텐츠 → JD 초안 + 🔧교정표 + ⚠️검토포인트표. **🔎 타 회사 JD 레퍼런스 검색**(직무명으로 검색 → 오른쪽 패널에 표시, 버튼으로 참고 콘텐츠에 넣기 가능). live=web_search 실검색 / mock=예시 브리프.
- **소싱 메시지** — 대상자/포지션 + 회사 소개 → 링크드인·이메일 개인화 메시지 + 검토포인트표
- **인터뷰 질문** — 포지션 JD(생성한 JD 선택 또는 붙여넣기) + 후보자 이력서(붙여넣기/.txt 업로드) + 인터뷰 유형 → 맞춤 질문지
- **인터뷰 결과 논의** — 인터뷰 기록 + 하이어링 매니저 평가 의견 → 강점·우려·추가 확인 사항으로 정리
- **채용 브랜딩** — 콘텐츠 유형·채널·타겟 + 회사 소개. **주제를 비우면 소재 6개 추천**, 주제를 채우면 **선택 채널 톤에 맞춰 본문 작성** + 대안 헤드라인 + 검토포인트표

각 기능은 입력 필드를 스스로 정의하고(`inputs`), `src/features/` 에 모듈로 분리돼 있습니다.
새 기능은 파일 추가 → `src/features/index.ts` 배열에 등록하면 화면 탭·입력폼에 자동 반영됩니다.
(JD 작성 결과는 세션에 저장돼 인터뷰 질문 탭의 JD 선택 드롭다운에 나타납니다.)

> 회사 고유의 미션·말투는 코드에 하드코딩하지 않습니다 — 전부 **참고 콘텐츠 입력에서 학습**합니다.
> 그래서 어떤 회사에든 그대로 쓸 수 있어요.

## 설치

전제: Node.js 18+ 설치.

```bash
cd recruiting-jd-bot
npm install
cp .env.example .env      # .env 를 열어 ANTHROPIC_API_KEY 입력 (없어도 mock 모드로 동작)
```

## 공개 배포 (Render — 링크 하나로 접속)

이 저장소에는 `render.yaml` 이 포함돼 있어, [Render](https://render.com) 무료 플랜으로 바로 배포할 수 있어요.

1. render.com 가입(GitHub 계정으로) → **New → Blueprint**
2. 이 저장소(`recruiting-bot-demo`) 선택 → `render.yaml` 자동 인식 → **Apply**
3. 몇 분 뒤 `https://<이름>.onrender.com` 공개 URL 생성 → 누구나 접속

기본은 **mock 모드(구조 미리보기)** 라 API 키 없이 무료로 돌아갑니다.
(⚠️ 공개 URL에서 실제 AI 생성을 켜려면 Render 환경변수에 `ANTHROPIC_API_KEY` 를 넣어야 하는데, 접속자 누구나 호출 → 과금됩니다. 공개 데모는 mock 권장.)

## 실행 — 웹 화면 (로컬)

```bash
npm run web
# → 브라우저에서 http://localhost:3000 열기
```

화면에서: 왼쪽에 채용 요청서 + **참고 콘텐츠**(이 회사의 기존 JD·소개글) 붙여넣기 → **생성** 클릭 → 오른쪽에 JD 초안·교정표·검토포인트표 표시.

- **키 없으면 자동 mock 모드** (과금 0, 직군별 예시 재생). 상단 배지로 mock/live 표시.
- 키 넣으면 같은 화면에서 실제 AI 생성으로 동작.
- 데모 흐름: `samples/회사소개_예시.txt` 를 참고 콘텐츠 칸에 붙여넣고, `samples/테크_채용요청_예시.txt` 내용을 요청서 칸에 붙여넣어 보세요.

## 실행 — CLI (터미널)

```bash
# 파일로 입력
npm run jd -- samples/테크_채용요청_예시.txt

# 또는 파이프로 입력
cat samples/테크_채용요청_예시.txt | npm run jd
```

### 키 없이 동작 확인 (mock 모드)

API 키가 아직 없으면 `--mock` 으로 **과금 없이** 프로그램 흐름(입력→스트리밍 출력)을
실제로 돌려볼 수 있습니다. 요청서의 직군 키워드를 보고 대응하는 예시 출력을 재생합니다.

```bash
npm run jd -- samples/테크_채용요청_예시.txt --mock
```

> mock은 **배선·UX 데모**용입니다. 실제 AI 생성(모델 호출 + 웹서치)은 키가 필요합니다.

## 샘플

`samples/` 에 참고용 입력 예시가 있습니다.
mock 모드는 고정 파일을 재생하지 않고 **입력값(직무·업무·요건·대상자·주제 등)을 그대로 반영**해 skeleton을 생성합니다.

- `회사소개_예시.txt` — 참고 콘텐츠 입력 예시 (봇이 이 톤·미션을 학습)
- `비테크_채용요청_예시.txt` / `테크_채용요청_예시.txt` / `크리에이티브_채용요청_예시.txt` — 직군별 요청서 예시

## (선택) 슬랙 앱

동일 코어(`generateJD`)를 슬랙에서 호출하는 래퍼가 있습니다. `api.slack.com/apps` 에서 앱을
만들고 Socket Mode를 켠 뒤 토큰 3종을 `.env` 에 넣으면 됩니다.

```bash
# .env 에 SLACK_BOT_TOKEN / SLACK_APP_TOKEN / SLACK_SIGNING_SECRET 추가 후
npm run slack
```

슬랙에서 `/jd작성 <요청서 텍스트>` → 스레드에 JD 묶음이 게시됩니다.
(알려진 한계: 슬랙은 마크다운 표를 렌더하지 않아 교정표/검토포인트표는 추후 Block Kit으로 변환 예정)

## 동작 (모듈 구조)

```
입력(요청서 + 참고 콘텐츠 / .txt / stdin / 슬랙)
  → src/web/server.ts  웹 서버 (메인 UI) — /api/generate
  → src/cli.ts         CLI 트리거 핸들러 + 입력 수집기
  → src/slack/app.ts   (선택) 슬랙 트리거 핸들러 — 같은 코어 재사용
  → src/core.ts        AI 처리기 (Claude API + web_search, 스트리밍) / mock 재생
  → src/features/*.ts  기능별 모듈(JD·소싱·면접·브랜딩) — 입력 필드·프롬프트 정의
  → src/tone-guide.ts  범용 JD 작성 규칙 (회사 고유 정보 없음 — 참고 콘텐츠에서 학습)
  → 출력               JD 초안 + 🔧교정표 + ⚠️검토포인트표 등
```

- 모델: `claude-opus-4-8` (adaptive thinking, effort high). `JD_BOT_MODEL` 로 변경 가능.
- 실시간 웹 리서치 기본 ON. 끄려면 `.env` 에 `JD_BOT_WEB_SEARCH=false`.

## 톤·구조 규칙 (요약)

`src/tone-guide.ts` 에 **범용 규칙만** 둡니다 (특정 회사 정보는 하드코딩하지 않음):
- 조직 소개 블록·미션·말투는 **참고 콘텐츠 입력에서 학습** (`REFERENCE_LEARNING_RULE`)
- 어조: role Intro=초대하는 톤 / 주요업무=서술형 / 자격·우대=`~분`
- 섹션명 붙여쓰기(주요업무·자격요건·우대사항), 테크 직군 전용 섹션
- 시장 표준 대비 누락 항목은 초안에 안 넣고 검토포인트표로만 올림
